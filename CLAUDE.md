# Working notes for Claude

## Brief bleed
Brief bleed = text from our briefing that leaks onto the page as visitor-facing copy:
narrating an instruction ("from a made-up brand"), exposing private status ("Locked",
"draft", "pending"), or explaining to nobody (text that exists only because the topic
came up in chat). Never write it. Keep the result of a decision, never commentary about it.

When I say "do a brief bleed pass", follow `.claude/commands/brief-bleed.md` (also available
as `/brief-bleed`).
