Title keys

Original: LEFT = level, RIGHT = speed, DOWN = next game, UP = previous game (as printed on the real units). Quick: LEFT/RIGHT = game, UP/DOWN = speed, ROTATE = level. Super and Screen start on Original.

On iPhone, Safari can’t go full screen from a web page. Use Share → Add to Home Screen and open it from there: no browser bars.

    Notes

    • Speed is how fast things move; level changes the challenge (Brick Fall starts with garbage rows, Snake gets obstacles, Brick Breaker gets more bricks…). In Brick Fall, ↑ is a hard drop.
    • Hold ROTATE in Snake or Road Racer for a turbo boost.
    • Your layout, colour and high scores are saved on this device.
    • On iPhone the ringer switch silences web audio.
